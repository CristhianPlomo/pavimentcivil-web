# Sistema Visual

Referencia oficial de color, tipografía y espaciado: [`DESIGN-SYSTEM.md`](DESIGN-SYSTEM.md).

## Color principal

Amarillo corporativo `#FFC000` (`--amber-500` / `--color-accent`).

Debe mantenerse como acento protagonista. No usarlo para párrafos ni textos largos.
